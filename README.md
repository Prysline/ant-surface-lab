# 螞蟻表面實驗室（Ant Surface Lab）

這是研究「三維場景中的二維表面行走」與鏡頭感受的網頁原型，暫不包含完整遊戲的採集、敵人或蟻群系統。

## 已有功能

- 一隻螞蟻、一份世界座標狀態、多個同步攝影機。
- A｜世界方向投影：將固定世界參考軸投影到目前的切平面，決定畫面上方。遇到投影退化時使用上一幀方向及備援軸。
- B｜平行搬運：沿著新舊表面法線的最小必要旋轉延續畫面上方方向。
- 兩個鏡頭均從當前表面法線方向觀察螞蟻；螞蟻在原地轉彎時鏡頭不跟著旋轉。
- 三個世界固定監視器：俯視 XZ、正視 XY、側視 YZ，點擊可放大。
- 立方體、圓柱、球體三種測試幾何；世界表面移動與鏡頭邏輯分開。
- 新增微縮餐具場景：一個展示台、一張四腳方凳、淺凹盤、蘋果與金屬湯匙（風格化 1/12 微縮道具，不使用真實尺寸）。
- 微縮場景 v0.2：道具與世界空間整體放大為原來的 4 倍（螞蟻模型不變）；蘋果在原比例上額外增大約 1.65～1.7 倍；湯匙柄延長並接到蘋果上半部的接觸點。
- 鍵盤 WASD／方向鍵、手機虛擬搖桿。先選 A 或 B 作為輸入方向基準，切換不改變螞蟻的位置。
- 固定時間步長的預設路徑重跑、暫停、重設、軌跡、座標、法線、朝向、A/B 方向差角。
- 響應式版面與可調渲染解析度。

## 微縮餐具場景：結構與可行走表面修正版

「微縮餐具場景」使用 4 倍世界尺寸，螞蟻本身不放大。七個起點：
P0 展示台地面、P1 凳腳中段、P2 木凳面、P3 盤內、
P4 蘋果冠部、P5 湯匙頸部、P6 凳面側壁。

### 盤子的圈足結構

- 盤子不再是一張直接覆在凳面上的高度曲面。
- 同一組封閉橫截面沿圓周旋轉，形成盤內、捲邊、側壁、凹進的盤底、外側圈足、圈足底部與內側壁。
- **唯一與凳面接觸的是半徑 0.43～0.55（模型單位）的底部環帶**，盤身其餘部分與凳面之間有約 0.06～0.22 模型單位的間隙。
- 表面移動從木凳面接到圈足外壁，再沿盤底、盤緣上到內側；**不能從盤外緣直接跨越空氣走上盤子**。
- miniatureGeometry.js 是橫截面、接觸點與可走幾何的共用來源，miniatureScene.js 只負責網格表現。

### 蘋果及湯匙

- 蘋果從舊版的完整橢球（下半部埋入盤子）改為**收窄果底、鼓起的肩部與凹下的冠部**，只在盤面上方建網格。果底接觸盤面，不會穿入凳子或陶瓷盤。
- 湯匙有可辨認的長橢圓匙面、略凹的內側、隆起的匙緣、較窄的匙頸與上斜的柄部。
- 柄部終點碰到蘋果側肩的一個明確接觸點，並維持**雙向可行走**的表面連接。
- 蘋果與湯匙不採寫實尺寸，仍以 1/12 模型道具的可讀性為主。

### 重要限制

- 目前是針對本場景編寫的解析曲面與接點，還不是支援任意 3D 物件的泛用碰撞／尋路系統。
- 盤子有實際幾何底部與圈足，並可沿作者定義的曲面行走；盤底與凳面距離非常近，是否容易操作需手機實際測試。
- 螞蟻由盤面接觸到蘋果的邊界與湯匙尖端轉接仍需實機確認是否順暢。單元測試主要驗證幾何與數學接觸，不取代畫面驗收。

## 開發

需 Node.js 22。安裝相依套件後啟動本機開發伺服器：

    npm install
    npm run dev

驗證及建置：

    npm run check
    npm run build

## 檔案

- src/core.js：向量運算、世界位置、既有三種幾何表面移動，無攝影機依賴。
- src/miniature.js：微縮場景的尺寸、相連表面與世界座標移動規則（純數學）。
- src/miniatureScene.js：使用相同尺寸建立凳子、陶瓷盤、蘋果與湯匙三維模型。
- src/cameras.js：A/B 鏡頭、畫面相對移動方向與固定監視器。
- src/main.js：Three.js 共用場景、螞蟻模型、五個攝影機的單一渲染器與輸入。
- src/style.css、index.html：手機及桌面介面。
- tests/core.test.js：表面幾何與平行搬運單元測試。
- .github/workflows/ci.yml、deploy.yml：GitHub Actions 檢查及 Pages 自動部署。

## 凳面側壁、鏡頭遮擋與湯匙接點

- 凳子不再只有上表面：四個垂直側壁已建立獨立可行走表面。可由凳面上緣翻到側壁，再往上爬回凳面；靠近支撐凳腳的位置也能由凳腳接到側壁。
- 直接進入未製作的凳面底面仍受阻，不會把凳面底緣當成可穿越的空氣。新增 **P6 凳面側壁** 測試起點。
- 先前蘋果到湯匙的判定要同時靠近單一接點 0.035 模型單位、面朝特定方向，手機搖桿難以準確操作。現在在蘋果接觸肩部附近加入有限的表面方向引導，讓玩家朝向匙柄時沿蘋果曲面逐步抵達接點，不傳送。微型藍色接觸標記也會出現在 A/B 視角。
- 「遮擋螞蟻的物件自動半透明」預設啟用，也可以關閉。每一個鏡頭分別利用射線判斷是否有道具擋住螞蟻，僅在該次鏡頭繪製期間降低遮擋**網格物件**的不透明度，隨後立即還原；不會改變導航碰撞或其他鏡頭。這是針對遮擋物件的半透明，尚不是只在螞蟻附近挖出局部透明圓孔。
- 新增上緣轉面、側面攀爬、凳腳與側面接觸、蘋果接點容錯及逐鏡頭透明狀態還原測試。仍需手機實機檢查效果與效能。

## 鏡頭過渡與手機捲動修正

- 鏡頭跨面預設使用 220 毫秒的顯示插值；可切換「立即」或「380 毫秒」來比較手感。
- A 和 B 的邏輯法線、畫面上方方向與螞蟻世界座標仍即時更新；只有可見攝影機的**位置與旋轉**進行平滑追蹤。固定監視器始終顯示實際位置。
- 手機網頁捲動時，三維攝影機的投影比例與渲染區域使用完整面板大小，**不因面板部分離開螢幕而縮放或拉伸**；超出螢幕的部分僅使用 WebGL scissor 裁切。
- WebGL canvas 的 CSS 尺寸與 renderer 使用的 CSS 像素一致，避免手機瀏覽器工具列展開／收起時，100vh 與 innerHeight 不一致而造成錯位。
- 新增回歸測試：面板上／下捲動裁切、CSS 座標偏移與縮放、A/B 鏡頭平滑過渡、立即切換與角色原地轉向。
- 如果瀏覽器啟用了「電腦版網站」，網頁可能由瀏覽器整體縮小到電腦佈局；這與 3D 畫面錯位是不同情況，手機建議關閉「電腦版網站」使用響應式介面。

## 已知限制

- 立方體使用明確折邊處理；圓柱及球體使用解析曲面。尚不支援任意網格表面、物件接觸生成橋梁或一般物理模擬。
- 尖角目前瞬間切換法線，沒有倒角平滑過渡。
- A 鏡頭在投影接近退化處需要實測；B 鏡頭的曲面閉合路線可能累積朝向差異，這不一定是錯誤。
- 預設路徑是從同一初始狀態重新執行，尚未實作手動錄製／逐幀倒轉。
- 手機效能尚需實機確認。若較慢，可選節能解析度。

原則：螞蟻運動不依賴觀察攝影機；只有玩家手動輸入的方向轉換會使用目前選定的 A/B 畫面座標。
